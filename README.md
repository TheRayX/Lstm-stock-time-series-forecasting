# Stock Time-Series Forecasting using LSTM

A deep learning project that uses a **Long Short-Term Memory (LSTM)** neural network for time-series forecasting of stock data.

## Overview

This project explores the use of recurrent neural networks for learning patterns in historical stock-price time-series data.

An LSTM model is trained on historical sequential data and used to generate forecasts based on previously observed values.

The project was developed as an exploration of applying deep learning techniques to financial time-series data.
